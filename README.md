✨ **TranslateX - Премиум Telegram Переводчик** 🚀

## 📋 Описание

TranslateX - это полнофункциональный Telegram-бот для перевода текстов на различные языки. Бот полностью на узбекском языке с красивым premium интерфейсом и emoji.

## 🌍 Поддерживаемые языки

- 🇷🇺 Русский
- 🇺🇸 Английский
- 🇵🇹 Португальский
- 🇩🇪 Немецкий
- 🇫🇷 Французский
- 🇪🇸 Испанский
- 🇮🇹 Итальянский
- 🇹🇷 Турецкий
- 🇺🇿 Узбекский

## ✨ Основные функции

✅ **Быстрый перевод** - Отправьте текст и выберите язык
✅ **Красивый интерфейс** - Premium emoji и inline кнопки
✅ **История переводов** - Все переводы сохраняются в БД
✅ **Админ панель** - Статистика, рассылка, бан/разбан
✅ **Антиспам** - Защита от злоупотреблений
✅ **SQLite БД** - Хранение данных пользователей
✅ **Async/Await** - Асинхронная обработка
✅ **FSM** - Управление состояниями

## 🚀 Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/yourusername/TranslateX.git
cd TranslateX
```

### 2. Создание виртуального окружения
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка .env файла
```bash
cp .env.example .env
```

Отредактируйте `.env` файл:
```
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
ADMIN_IDS=123456789,987654321
DATABASE_PATH=data/bot.db
LOG_LEVEL=INFO
```

### 5. Запуск бота
```bash
python main.py
```

## 🔧 Конфигурация

### config.py
- `BOT_TOKEN` - Токен Telegram бота
- `ADMIN_IDS` - ID администраторов (через запятую)
- `DATABASE_PATH` - Путь к БД
- `LOG_LEVEL` - Уровень логирования
- `LANGUAGES` - Поддерживаемые языки
- `EMOJI_PREMIUM` - Premium emoji для интерфейса

## 📊 База данных

### Таблица users
- `user_id` - ID пользователя
- `username` - Юзернейм
- `first_name` - Имя
- `language` - Язык по умолчанию
- `translations_count` - Количество переводов
- `is_banned` - Статус бана
- `created_at` - Дата регистрации
- `last_used` - Последнее использование

### Таблица translations
- `id` - ID записи
- `user_id` - ID пользователя
- `source_text` - Исходный текст
- `translated_text` - Переведенный текст
- `source_lang` - Исходный язык
- `target_lang` - Целевой язык
- `created_at` - Дата перевода

### Таблица spam_log
- `id` - ID записи
- `user_id` - ID пользователя
- `action` - Тип действия
- `timestamp` - Время действия

## 📝 Логирование

Все события логируются в консоль с указанием времени, модуля и уровня логирования.

Уровни логирования:
- `DEBUG` - Детальная информация
- `INFO` - Информационные сообщения
- `WARNING` - Предупреждения
- `ERROR` - Ошибки
- `CRITICAL` - Критические ошибки

## 🐛 Решение проблем

### Бот не запускается
1. Проверьте наличие файла `.env`
2. Убедитесь, что `BOT_TOKEN` установлен правильно
3. Проверьте логи для деталей ошибки

### Ошибка при переводе
1. Проверьте интернет соединение
2. Убедитесь, что текст не превышает 5000 символов
3. Попробуйте позже (возможно проблема с API)

### БД не инициализируется
1. Проверьте права доступа к директории `data/`
2. Убедитесь, что путь в `DATABASE_PATH` корректен
