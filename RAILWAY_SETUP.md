# Настройка на Railway

## Переменные окружения

На Railway нужно установить следующие переменные окружения в разделе "Variables":

### Обязательные:
- **BOT_TOKEN** - токен Telegram бота (получить от @BotFather)
  - Пример: `8756107034:AAHNk2vV2bf-JGWsICeb2mBozRVNqaKJDCk`

### Опциональные:
- **ADMIN_IDS** - ID администраторов (через запятую, без пробелов)
  - Пример: `8784918764,123456789`
  - Если не установлено, админ-функции будут недоступны

- **DATABASE_PATH** - путь к БД (по умолчанию: `data/bot.db`)
  - Пример: `data/bot.db`

- **LOG_LEVEL** - уровень логирования (по умолчанию: `INFO`)
  - Возможные значения: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`

## Шаги для развертывания:

1. Перейти на https://railway.app
2. Создать новый проект или открыть существующий
3. Подключить GitHub репозиторий
4. Перейти в "Variables" и добавить переменные окружения
5. Railway автоматически развернет приложение

## Проверка статуса:

- Перейти в "Deployments" чтобы увидеть логи
- Если есть ошибки, они будут видны в логах

## Если сервер не работает:

1. Проверить логи в Railway (Deployments → Logs)
2. Убедиться, что BOT_TOKEN установлен и правильный
3. Проверить, что rootDirectory в railway.json установлен на "TranslateX"
4. Перезапустить приложение (Redeploy)

## Команда для локального тестирования:

```bash
cd TranslateX
python main.py
```

Бот должен вывести:
```
✨ TranslateX бот запущен!
💎 Версия: 1.0.0
⚡ Ожидание сообщений...
```
