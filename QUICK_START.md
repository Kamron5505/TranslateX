## За 5 минут до первого перевода

### 1️⃣ Установка (2 минуты)

```bash
# Клонирование
git clone https://github.com/yourusername/TranslateX.git
cd TranslateX

# Виртуальное окружение
python -m venv venv
venv\Scripts\activate  # Windows
# или
source venv/bin/activate  # Linux/Mac

# Зависимости
pip install -r requirements.txt
```

### 2️⃣ Конфигурация (2 минуты)

```bash
# Копирование .env
copy .env.example .env  # Windows
# или
cp .env.example .env  # Linux/Mac

# Отредактируйте .env:
# BOT_TOKEN=YOUR_TOKEN_HERE
# ADMIN_IDS=YOUR_ID_HERE
```

### 3️⃣ Запуск (1 минута)

```bash
python main.py
```

## Решение проблем

### Ошибка: "ModuleNotFoundError"
```bash
pip install -r requirements.txt
```

### Ошибка: "BOT_TOKEN не установлен"
Проверьте файл `.env` и убедитесь, что токен установлен.

### Бот не отвечает
1. Проверьте интернет
2. Проверьте токен
3. Посмотрите логи в консоли
