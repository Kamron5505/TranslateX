# 🚀 Инструкция по установке и запуску TranslateX

## Шаг 1: Получение токена Telegram бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: TranslateX Bot)
   - Введите юзернейм бота (должен заканчиваться на `_bot`)
4. Скопируйте полученный токен

## Шаг 2: Подготовка окружения

### Windows

```bash
# Создание виртуального окружения
python -m venv venv

# Активация
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### Linux/Mac

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

## Шаг 3: Конфигурация

1. Откройте файл `.env`
2. Замените `YOUR_BOT_TOKEN_HERE` на ваш токен:
   ```
   BOT_TOKEN=123456789:ABCdefGHIjklmnoPQRstuvWXYZ
   ```
3. Установите ваш ID администратора (узнайте через @userinfobot):
   ```
   ADMIN_IDS=123456789
   ```

## Шаг 4: Запуск бота

```bash
python main.py
```

Вы должны увидеть:
```
✨ TranslateX бот запущен!
💎 Версия: 1.0.0
⚡ Ожидание сообщений...
```

## Шаг 5: Тестирование

1. Откройте Telegram
2. Найдите вашего бота по юзернейму
3. Отправьте `/start`
4. Отправьте любой текст
5. Выберите язык для перевода

## 🔧 Решение проблем

### Ошибка: "BOT_TOKEN не установлен"
- Проверьте файл `.env`
- Убедитесь, что токен скопирован правильно
- Перезагрузите приложение

### Ошибка: "ModuleNotFoundError"
- Убедитесь, что виртуальное окружение активировано
- Переустановите зависимости: `pip install -r requirements.txt`

### Бот не отвечает
- Проверьте интернет соединение
- Убедитесь, что токен активен
- Посмотрите логи в консоли

## 📊 Структура БД

База данных автоматически создается при первом запуске в файле `data/bot.db`

## 🎮 Команды для тестирования

```
/start - Начало работы
/help - Справка
/admin - Админ панель (если вы администратор)
```

## 💡 Советы

- Сохраняйте токен в безопасном месте
- Не делитесь токеном с другими
- Регулярно проверяйте логи
- Используйте разные ID администраторов для разных ботов
