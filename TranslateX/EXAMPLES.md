# 📚 Примеры использования TranslateX

## Пример 1: Простой перевод

**Пользователь отправляет:**
```
Hello, how are you?
```

**Бот предлагает выбрать язык:**
```
🌍 Выберите язык для перевода:
[🇷🇺] [🇺🇸] [🇵🇹] [🇩🇪] [🇫🇷] [🇪🇸] [🇮🇹] [🇹🇷] [🇺🇿]
```

**Пользователь выбирает 🇷🇺 (Русский)**

**Бот отвечает:**
```
✅ Перевод выполнен!

🪄 Целевой язык: Русский

📝 Результат:
```
Привет, как дела?
```

💎 Отправьте еще текст для перевода!
```

```
💎 Отправьте еще текст для перевода!
```

## Пример 10: Безопасность

### Проверка администратора
```python
if message.from_user.id not in ADMIN_IDS:
    await message.answer(f"{EMOJI_PREMIUM['error']} Доступ запрещен!")
    return
```

### Проверка бана
```python
if await db.is_banned(user_id):
    await message.answer(f"{EMOJI_PREMIUM['error']} Вы забанены!")
    return
```

### Антиспам
```python
spam_count = await db.get_spam_count(user_id, minutes=1)
if spam_count > 10:
    await message.answer(f"{EMOJI_PREMIUM['error']} Слишком много запросов!")
    return
```
