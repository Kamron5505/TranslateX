# ❓ Часто задаваемые вопросы (FAQ)

## 🚀 Установка и запуск

### Q: Как установить бота?
**A:** Следуйте инструкциям в файле `SETUP.md`. Кратко:
1. Установите Python 3.8+
2. Клонируйте репозиторий
3. Создайте виртуальное окружение
4. Установите зависимости: `pip install -r requirements.txt`
5. Создайте `.env` файл с вашим BOT_TOKEN
6. Запустите: `python main.py`

### Q: Где получить BOT_TOKEN?
**A:** 
1. Откройте Telegram и найдите @BotFather
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен в `.env` файл

### Q: Какая версия Python нужна?
**A:** Python 3.8 или выше. Проверьте версию: `python --version`

### Q: Как активировать виртуальное окружение?
**A:**
- **Windows:** `venv\Scripts\activate`
- **Linux/Mac:** `source venv/bin/activate`

### Q: Бот не запускается, что делать?
**A:** Проверьте:
1. Установлены ли все зависимости: `pip install -r requirements.txt`
2. Правильно ли установлен BOT_TOKEN в `.env`
3. Активировано ли виртуальное окружение
4. Посмотрите логи для деталей ошибки

## 🌍 Функциональность

### Q: Какие языки поддерживаются?
**A:** 9 языков:
- 🇷🇺 Русский
- 🇺🇸 Английский
- 🇵🇹 Португальский
- 🇩🇪 Немецкий
- 🇫🇷 Французский
- 🇪🇸 Испанский
- 🇮🇹 Итальянский
- 🇹🇷 Турецкий
- 🇺🇿 Узбекский

### Q: Как добавить новый язык?
**A:** Отредактируйте `config.py`:
```python
LANGUAGES = {
    ...
    "🇯🇵": "ja",  # Новый язык
}

LANGUAGE_NAMES = {
    ...
    "ja": "日本語",
}
```

### Q: Какой максимальный размер текста?
**A:** 5000 символов. Это ограничение API перевода.

### Q: Как работает перевод?
**A:** Бот использует Google Translate API через библиотеку `deep-translator`.

### Q: Почему перевод медленный?
**A:** Это может быть из-за:
- Медленного интернета
- Перегрузки API
- Большого размера текста

### Q: Можно ли переводить с определенного языка?
**A:** Да, бот автоматически определяет язык исходного текста.

## 👥 Пользователи

### Q: Как пользователь выбирает язык?
**A:** Пользователь отправляет текст, затем выбирает язык из inline кнопок.

### Q: Сохраняется ли история переводов?
**A:** Да, все переводы сохраняются в SQLite БД.

### Q: Как пользователь может установить язык по умолчанию?
**A:** Нажав на кнопку "Выбрать язык" и выбрав нужный язык.

### Q: Что происходит, если пользователь забанен?
**A:** Забанный пользователь не может использовать бота и видит сообщение об ошибке.

### Q: Как долго хранятся данные пользователя?
**A:** Данные хранятся в БД неограниченно долго, пока вы не удалите их вручную.

## 🛡️ Безопасность и администрирование

### Q: Как стать администратором?
**A:** Установите ваш ID в переменной `ADMIN_IDS` в `.env` файле.

### Q: Как узнать свой ID в Telegram?
**A:** Отправьте сообщение боту @userinfobot

### Q: Как забанить пользователя?
**A:** 
1. Отправьте `/admin`
2. Нажмите "Бан/Разбан"
3. Отправьте ID пользователя

### Q: Как разбанить пользователя?
**A:** Повторите процесс бана, но выберите "Разбан"

### Q: Как отправить рассылку?
**A:**
1. Отправьте `/admin`
2. Нажмите "Рассылка"
3. Отправьте текст сообщения
4. Подтвердите отправку

### Q: Как просмотреть статистику?
**A:**
1. Отправьте `/admin`
2. Нажмите "Статистика"

### Q: Что такое антиспам?
**A:** Система, которая ограничивает количество запросов пользователя в минуту (максимум 10 запросов за 1 минуту).

### Q: Как отключить антиспам?
**A:** Отредактируйте `handlers.py` и измените лимит в функции `handle_text`.

## 💾 База данных

### Q: Где хранится БД?
**A:** По умолчанию в файле `data/bot.db`

### Q: Как сделать резервную копию БД?
**A:** Просто скопируйте файл `data/bot.db` в безопасное место.

### Q: Как восстановить БД из резервной копии?
**A:** Замените текущий файл `data/bot.db` на резервную копию.

### Q: Как очистить БД?
**A:** Удалите файл `data/bot.db` и перезагрузите бота.

### Q: Как экспортировать данные из БД?
**A:** Используйте SQLite инструменты или напишите скрипт на Python.

### Q: Какие таблицы есть в БД?
**A:** 
- `users` - Информация о пользователях
- `translations` - История переводов
- `spam_log` - Логирование спама

## 🐛 Решение проблем

### Q: Ошибка "ModuleNotFoundError: No module named 'aiogram'"
**A:** Установите зависимости: `pip install -r requirements.txt`

### Q: Ошибка "BOT_TOKEN не установлен"
**A:** Проверьте файл `.env` и убедитесь, что BOT_TOKEN установлен правильно.

### Q: Бот не отвечает на сообщения
**A:** 
1. Проверьте интернет соединение
2. Проверьте, активен ли токен
3. Посмотрите логи для ошибок
4. Перезагрузите бота

### Q: Ошибка при переводе
**A:**
1. Проверьте интернет соединение
2. Убедитесь, что текст не превышает 5000 символов
3. Попробуйте позже (возможно проблема с API)

### Q: БД не инициализируется
**A:**
1. Проверьте права доступа к директории `data/`
2. Убедитесь, что путь в `DATABASE_PATH` корректен
3. Удалите файл `data/bot.db` и перезагрузите бота

### Q: Высокое использование памяти
**A:**
1. Перезагрузите бота
2. Проверьте размер БД
3. Очистите старые логи

### Q: Бот работает медленно
**A:**
1. Проверьте размер БД
2. Оптимизируйте запросы к БД
3. Используйте более мощный сервер

### Q: Как ускорить перевод?
