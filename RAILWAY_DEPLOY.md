# 🚀 Развертывание TranslateX на Railway

## Что такое Railway?

Railway - это облачная платформа для развертывания приложений. Она бесплатна для начинающих и очень проста в использовании.

## Шаг 1: Подготовка GitHub репозитория

1. Создайте GitHub аккаунт (если его нет)
2. Создайте новый репозиторий
3. Загрузьте все файлы проекта:

```bash
git init
git add .
git commit -m "Initial commit: TranslateX bot"
git branch -M main
git remote add origin https://github.com/yourusername/TranslateX.git
git push -u origin main
```

## Шаг 2: Регистрация на Railway

1. Откройте https://railway.app
2. Нажмите "Sign Up"
3. Выберите "Sign up with GitHub"
4. Авторизуйтесь через GitHub

## Шаг 3: Создание проекта на Railway

1. На главной странице нажмите "New Project"
2. Выберите "Deploy from GitHub repo"
3. Выберите ваш репозиторий TranslateX
4. Railway автоматически обнаружит Python проект

## Шаг 4: Установка переменных окружения

1. В Railway перейдите в "Variables"
2. Добавьте переменные:

```
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
ADMIN_IDS=123456789,987654321
DATABASE_PATH=data/bot.db
LOG_LEVEL=INFO
```

**Где получить BOT_TOKEN:**
- Откройте Telegram
- Найдите @BotFather
- Отправьте `/newbot`
- Следуйте инструкциям
- Скопируйте токен

## Шаг 5: Развертывание

1. Railway автоматически начнет развертывание
2. Дождитесь завершения (обычно 2-3 минуты)
3. Проверьте логи для ошибок

## Шаг 6: Проверка статуса

1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте `/start`
4. Если бот ответил - все работает! ✅

## Решение проблем

### Ошибка: "Build failed"
- Проверьте, что все файлы загружены
- Убедитесь, что requirements.txt в корне репозитория
- Проверьте логи Railway

### Ошибка: "Bot not responding"
- Проверьте BOT_TOKEN в переменных окружения
- Убедитесь, что токен правильный
- Проверьте логи в Railway

### Ошибка: "Database error"
- Railway автоматически создаст директорию data/
- Если ошибка продолжается, проверьте права доступа

## Мониторинг

1. В Railway перейдите в "Logs"
2. Смотрите логи приложения в реальном времени
3. Проверяйте ошибки и предупреждения

## Обновление кода

1. Внесите изменения в код
2. Загрузьте на GitHub:

```bash
git add .
git commit -m "Update: description of changes"
git push
```

3. Railway автоматически перестроит и развернет приложение

## Остановка приложения

1. В Railway перейдите в "Settings"
2. Нажмите "Delete"
3. Подтвердите удаление
