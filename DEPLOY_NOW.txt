Шаг 1: Загрузить на GitHub (2 минуты)
  git init
  git add .
  git commit -m "TranslateX bot"
  git branch -M main
  git remote add origin https://github.com/YOUR_USERNAME/TranslateX.git
  git push -u origin main

Шаг 2: Создать проект на Railway (1 минута)
  1. Откройте https://railway.app
  2. Нажмите "New Project"
  3. Выберите "Deploy from GitHub repo"
  4. Выберите ваш репозиторий TranslateX

Шаг 3: Установить переменные окружения (1 минута)
  1. В Railway перейдите в "Variables"
  2. Добавьте:
     BOT_TOKEN=YOUR_BOT_TOKEN_HERE
     ADMIN_IDS=123456789

Шаг 4: Развертывание (1 минута)
  Railway автоматически развернет приложение!
