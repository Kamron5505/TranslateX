1. Установка:
   git clone https://github.com/yourusername/TranslateX.git
   cd TranslateX
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt

2. Конфигурация:
   copy .env.example .env
   # Отредактируйте .env с вашим BOT_TOKEN

3. Запуск:
   python main.py

4. Тестирование:
   Откройте Telegram и найдите вашего бота
   Отправьте /start
   Отправьте текст для перевода
